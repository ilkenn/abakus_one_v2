# Abaküs Gemini Context Pack

## Kurulum

1. ZIP dosyasını açın.
2. PowerShell ile bu klasöre girin.
3. Aşağıdaki komutu çalıştırın:

```powershell
powershell -ExecutionPolicy Bypass -File .\install_docs.ps1 -ProjectPath "C:\Projects\abakus_one_v2"
```

Alternatif olarak `docs` klasörünü doğrudan Flutter projesinin köküne kopyalayabilirsiniz.

## Kullanım

Her Gemini oturumunda önce:

- `docs/gemini_master_prompt.md`
- İlgili mimari belgeler
- Değiştirilecek mevcut dosyaların gerçek içerikleri
- Ekran tasarımı

paylaşılmalıdır.
